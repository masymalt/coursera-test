# MP3 Artist Photo Finder

Веб-приложение, которое:
1. Принимает MP3-файл от пользователя.
2. Читает теги `Artist` и `Title`.
3. Выводит исполнителя и название трека.
4. Загружает и показывает 5 фотографий исполнителя.

## Стек

- Python 3.10+
- Flask
- Mutagen (чтение ID3 тегов из MP3)
- Wikimedia Commons API (поиск изображений)

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 app.py
```

Откройте в браузере: `http://127.0.0.1:5000`

## Как использовать

1. Нажмите «Выбрать MP3-файл».
2. Выберите mp3 с заполненными тегами `Artist` и `Title`.
3. Нажмите «Распознать».
4. На странице появятся:
   - исполнитель,
   - название песни,
   - до 5 фотографий исполнителя.

## Ограничения

- Поддерживается только формат `.mp3`.
- Если в файле нет ID3 тегов, приложение вернет сообщение об ошибке.
- Количество фото зависит от доступных изображений в Wikimedia Commons.
